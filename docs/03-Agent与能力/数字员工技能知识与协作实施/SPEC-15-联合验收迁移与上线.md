## 迁移检查

- 只新增迁移，先核对真实 MySQL 版本、旧迁移最高编号、唯一键、长文本与外键策略。
- 模式扩展对旧行可空/兼容；V1、旧 Session 身份与物理键保留。旧截断正文无法补全，不伪造结果。
- 事件回填保持旧 cursor，用新高位游标补缺投影；确认无 INTERNAL 泄漏，升级期间新旧分配器不同时写。
- 新 profile 上线前整体升级/停止旧 Worker；不让旧二进制认领 V2 或 RECOVERY_REQUIRED。
- 回退到可识别 V2/保护性拒绝的兼容版本，关闭新 profile 新建受理，保留查询/停止与持久事实；不删 state/结果/outbox 回退。
