# SPEC-05 前端与功能验收

状态：实施中。依赖[详细设计](工具与MCP实施详细设计.md)。

管理员界面提供连接登记/测试、逐用户发现候选、逐工具批准、停用和员工能力选择中的 MCP 来源标识；禁止展示 Token、原始手机号或其他用户的隐藏工具名。错误提示区分登录失效、无权限、不可用、未知写结果。按钮状态遵守服务端决定，不用前端校验代替授权。

功能测试按“连接登记 → A/B 发现不同工具 → 批准子工具 → 员工绑定发布 → A/B 创建 Run → 调用及资源拒绝 → 停用与旧 Run → 写操作幂等/核查”顺序执行。记录测试环境、命令、实际响应、失败与未覆盖项；至少执行 Java 定向测试、跨模块构建、前端构建及模拟器真实 HTTP 调用。没有真实身份系统或生产 MCP Server 时不得写成已通过生产验收。

本轮落地：管理员页面提供连接、发现、批准、启停，审核时展示输入/输出 Schema；员工页展示所选工具名、来源、动作与确认规则。持久差异视图读取当前管理员在所选连接下最近两次成功发现，可查看快照时间、连接修订和工具字段变动；此视图不提供历史批准按钮。Java 全模块、MySQL+HTTP 功能链路、确定性假模型的 Harness→模拟 MCP→模型恢复和持久 Worker 交接测试见[模拟闭环报告](../../07-测试报告/工具与MCP模拟闭环功能验收报告.md)；差异视图的 MySQL 与页面构建结果见[增量验收报告](../../07-测试报告/MCP持久发现差异视图验收报告.md)。独立连接健康页、浏览器人工操作、真实身份/Server、真实模型和跨进程重启尚未验证或交付。
