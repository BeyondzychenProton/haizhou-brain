# 海卓智慧大脑前端实现说明

> 状态：基础界面已实现；以下按 2026-09-28 代码更新。早期 v0 的构建记录保留在文末，不代表浏览器人工验收。
>
> 范围：Vue 3 + TypeScript + Vite 前端，以及支撑前端真实链路的最小后端查询接口。

## 1. 实现目标

前端 v0 的核心不是复制后端领域模型，而是把已经存在的身份、数字员工、Session、Run 和 RunEvent 链路变成可使用的界面：

```text
登录
  ↓ Cookie + Redis WebSession
数字员工
  ↓ 创建新 Session
会话
  ↓ 一条消息创建一个 Run
会话级 SSE；断线后补读与轮询降级
  ↓ Presenter 转换
聊天消息 + 运行详情
```

普通用户看到“数字员工 → 会话 → 消息”；Run、DefinitionVersion 和 Event 只在运行详情中出现。

## 2. 实现模块

| 模块 | 职责 |
| --- | --- |
| `src/api/httpClient.ts` | Cookie、CSRF、401 跳转和统一 HTTP 配置 |
| `src/api/auth.ts` | 登录、当前用户、退出登录 |
| `src/api/app.ts`、`src/api/runStream.ts` | 数字员工、Session、Run、历史事件、SSE 和运行控制请求 |
| `src/stores/auth.ts` | 当前登录用户和管理员菜单状态 |
| `src/stores/app.ts` | 数字员工和最近 Session 展示状态 |
| `src/presenters/runEventPresenter.ts` | 将持久事件转换为聊天消息和计划展示 |
| `views/app/SessionView.vue` | 历史消息、实时流、排队、取消、运行中引导、工具确认和 Run Inspector |
| `views/admin/` | 用户、能力、员工定义及 MCP 连接/工具管理 |

## 3. 状态边界

后端是业务事实来源。前端只保存当前用户展示信息、页面数据、会话事件游标和界面状态；历史记录与运行事实以服务端为准。

前端不保存 JWT，也不把 UserId、角色或资源所有权作为可信权限依据。

## 4. Run/Event 处理

一条消息通过当前真实路径创建 Run：

```text
POST /api/v1/sessions/{sessionId}/runs
GET  /api/v1/sessions/runs/{runId}
GET  /api/v1/sessions/{sessionId}/timeline
GET  /api/v1/sessions/{sessionId}/stream?after={cursor}
GET  /api/v1/sessions/{sessionId}/events?after={cursor}
```

页面先加载历史，再用会话级 SSE 接收增量；断线后以持久游标补读，必要时轮询降级。历史时间线响应的 `runId` 必须是与会话流一致的字符串（不是 `{value: ...}` 对象）；展示层用它区分不同 Run 的消息，否则多轮消息会被错误去重或覆盖。`USER_INPUT` 映射为用户气泡，`AGENT_MESSAGE` 和 `MODEL_DELTA` 映射为助手消息，计划快照单独展示；运行事件保留在 Inspector 中。

状态机器以服务端枚举为准。展示层只做文案映射：

```text
QUEUED → 正在等待
RUNNING → 正在处理
WAITING_TOOL → 等待工具执行
WAITING_CONFIRMATION → 等待继续操作 / 补充信息
SUCCEEDED → 已完成
FAILED → 执行失败
CANCELLED → 已取消
```

## 5. 为前端补充的后端查询能力

新增：

```text
GET /api/v1/employees
GET /api/v1/sessions?limit=20
```

前者只返回用户视图字段；后者根据已认证用户查询最近 Session。其后已补充会话历史、SSE、Run 控制、工具确认，以及管理员用户与 MCP 管理接口；API 路径以当前 Controller 为准。

## 6. 当前边界

- 历史 Session 可恢复消息；实时更新依赖后端 SSE，断线时补读/轮询。Run Worker 未启用时仍可能停在 `QUEUED`。
- 管理中心包含用户、能力、定义及 MCP 页面；真实 MCP 用户凭证与 Server 尚未接入，模拟能力不能等同生产可用。
- 前端构建与类型检查已有通过记录；本机当前配置模型触发模拟 MCP 工具的浏览器自动交互已完成，用户人工操作及真实第三方 Server 仍需专项验收。

## 7. 启动方式

在 `haizhuo-brain-web` 目录执行：

```text
npm install
npm run dev
```

开发服务器默认运行在 `5173`，`/api` 请求代理到后端 `8080`。
