## 目录约定

```text
docs/
├── 文档索引.md
├── 01-平台总览/       # 产品、对象、模块和整体架构
├── 02-身份与会话/     # 用户、管理员、Session、Run 和权限
├── 03-Agent与能力/    # Agent 定义、能力、发布和运行时装配
├── 04-渠道与执行/     # 渠道接入、执行链路、控制和 Mock 退出
├── 05-业务闭环/       # 业务场景设计和实现方案
├── 06-开发指南/       # 框架学习、源码阅读和接入验证
├── 07-测试报告/       # 当前及历史验证报告
└── 08-前端/            # 前端实现、架构和验证说明
```

维护规则：新增或移动文档时同步更新本索引；文档文件名使用中文主题名；设计文档标注状态、版本和适用范围；历史报告保留原始结论并明确其是否仍代表当前能力；仓库内链接使用相对路径。

设计文档不单独证明功能已实现。会议室 Mock 已退出；历史测试报告只证明当时的原型或专项验证结果，当前实现以源码、迁移和可复现测试为准。
