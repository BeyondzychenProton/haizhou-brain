## 目标边界

- 本机会议室 Mock 闭环；无前端、无正式登录、无真实会议室接入。
- 服务端固定测试身份，仅本机访问；请求体不能指定 `userId`。
- AgentScope 实际调用配置的 OpenAI 兼容模型和受控会议室工具。
- MySQL 持久化 Session、Run、幂等信息、事件和 Mock 预定。
- 配置从独立 YAML 文件读取；密钥和本地密码不进入 Git、文档、日志或测试报告。
- Redis 不作为本轮业务正确性的必要条件。
